 Laptop Price Analysis

Exploratory data analysis of 1,245 laptop records to find what influences price.

## Business question
Which laptop specifications and brands drive price?

## Tools
Python, Pandas, NumPy, Matplotlib

## What I did
1. Cleaned the data: missing values, outlier detection and validation.
2. Engineered features from storage, screen resolution, touchscreen capability, CPU speed and display details.
3. Ran correlation and comparative analysis against price.
4. Visualized the effect of RAM, storage, screen resolution, GPU and brand on price.
